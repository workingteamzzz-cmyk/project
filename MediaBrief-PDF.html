Generator PDF Laporan

Ubah file HTML laporan pantauan media menjadi PDF — penuh, tidak terpotong, link tetap bisa diklik.
Butuh koneksi internet. Tiap laporan dirender memakai Tailwind, Chart.js, dan Google Fonts aslinya, jadi hasil PDF sama persis dengan tampilan di browser. Semua proses berjalan di perangkat Anda — file laporan tidak diunggah ke mana pun. Logo dan gambar dari server lain diambil otomatis (bila perlu lewat proxy gambar publik) lalu disimpan di browser untuk laporan berikutnya.
